## 🚀 EXPORT ET IMPORT

### Étape 1: Exporter le thème

```bash
cd /workspace
./export-shopify-theme.sh
```

Ou manuellement:

```bash
cd /workspace/theme_shopify
zip -r ../flawless-beauty-shopify-theme.zip .
```

### Étape 2: Importer dans Shopify

1. **Admin Shopify** → Boutique en ligne → Thèmes
2. **Ajouter un thème** → Importer un fichier ZIP
3. **Uploader** `flawless-beauty-shopify-theme.zip`
4. **Attendre** l'import
5. **Personnaliser** le thème

### Étape 3: Configuration rapide

1. **Couleurs**: Appliquer #F792CC comme couleur principale
2. **Polices**: Sélectionner Playfair Display et Inter
3. **Logo**: Uploader votre logo
4. **Menus**: Configurer navigation header et footer
