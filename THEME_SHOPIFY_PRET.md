## 🚀 Comment Importer le Thème sur Shopify

### Étape 1 : Télécharger le Fichier ZIP

Le fichier `flawlessbeauty-theme.zip` est prêt à être téléchargé depuis votre workspace.

### Étape 2 : Se Connecter à Shopify

1. Allez sur `votre-boutique.myshopify.com/admin`
2. Connectez-vous avec vos identifiants

### Étape 3 : Importer le Thème

1. Menu **Boutique en ligne** → **Thèmes**
2. Cliquez sur **Ajouter un thème**
3. Sélectionnez **Importer un fichier**
4. Uploadez `flawlessbeauty-theme.zip`
5. Attendez la confirmation (1-3 minutes)

### Étape 4 : Personnaliser

1. Cliquez sur **Personnaliser** pour configurer :
   - Logo FlawlessBeauty
   - Carrousel Hero (3-10 slides)
   - Grille de catégories (6 items recommandés)
   - Footer (coordonnées, réseaux sociaux)

### Étape 5 : Publier

1. Une fois satisfait, cliquez sur **Publier**
2. Votre nouveau thème est en ligne ! 🎉

## 🆘 Dépannage

### Le thème ne s'importe pas
→ Vérifiez la structure du ZIP (pas de dossier parent)

### Les couleurs roses ne s'affichent pas
→ Forcez le rechargement : Ctrl+Shift+R (Cmd+Shift+R sur Mac)

### Le carrousel ne défile pas
→ Vérifiez qu'Alpine.js est chargé (console navigateur F12)

### La navigation mobile est invisible
→ Testez sur un vrai mobile (pas juste un redimensionnement)
