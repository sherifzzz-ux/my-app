🚀  PROCHAINES ÉTAPES POUR DÉPLOYER
═══════════════════════════════════════════════════════════════════════════════

1️⃣  PRÉPARER LA BASE DE DONNÉES
    → Créer une base PostgreSQL (Supabase, Neon, Railway)
    → Récupérer la DATABASE_URL

2️⃣  CONFIGURER LES SERVICES
    → PayTech : https://paytech.sn
    → Uploadthing : https://uploadthing.com
    → Resend : https://resend.com
    → OAuth : Google Cloud Console & GitHub

3️⃣  DÉPLOYER SUR VERCEL
    → Aller sur https://vercel.com/new
    → Importer votre repository GitHub
    → Configurer les variables d'environnement
    → Cliquer sur "Deploy"

4️⃣  VÉRIFIER LE DÉPLOIEMENT
    → Tester la page d'accueil
    → Vérifier l'authentification
    → Tester le processus d'achat
    → Accéder au dashboard admin

⚡  COMMANDES UTILES

DÉVELOPPEMENT LOCAL :

DÉPLOIEMENT VERCEL :

  $ vercel --prod

🐛  RÉSOLUTION DES PROBLÈMES
═══════════════════════════════════════════════════════════════════════════════

SI LE BUILD ÉCHOUE :
  1. Vérifier les logs Vercel (Project > Deployments > Build Logs)
  2. S'assurer que DATABASE_URL est définie
  3. Vérifier que Prisma génère correctement

SI ERREUR AU RUNTIME :
  1. Vérifier les logs : Project > Logs
  2. Vérifier NEXTAUTH_URL (doit pointer vers Vercel)
  3. Vérifier que NEXTAUTH_SECRET est défini

SI PAYTECH NE FONCTIONNE PAS :
  1. Vérifier PAYTECH_API_KEY et PAYTECH_API_SECRET
  2. Commencer avec PAYTECH_ENV=test
  3. Configurer le webhook PayTech
