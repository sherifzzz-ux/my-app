## 📦 3 Étapes pour Importer

### 1️⃣ Créer le ZIP
```bash
cd theme_shopify
./build-theme.sh
```
→ Fichier `flawlessbeauty-theme.zip` créé

### 2️⃣ Importer sur Shopify
1. Admin Shopify → Boutique en ligne → Thèmes
2. Ajouter un thème → Importer un fichier
3. Uploader `flawlessbeauty-theme.zip`

### 3️⃣ Configurer
1. Personnaliser le thème
2. Ajouter carrousel (3-10 slides)
3. Ajouter grille catégories (6 items)
4. Configurer footer
5. Publier !
